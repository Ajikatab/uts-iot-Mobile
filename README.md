# IoT Data Mobile App

A Flutter mobile application for presenting IoT sensor readings.

## Features
- Displays temperature and humidity summaries, including monthly and maximum values
- Uses an HTTP client and SVG rendering

## Tech stack
- Flutter and Dart
- HTTP
- SVG rendering

## Setup
Install Flutter and platform tooling, run `flutter pub get`, configure the service endpoint expected by the app, and launch with `flutter run`.
